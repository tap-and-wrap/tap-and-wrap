## Decisions and safeguards

- Keep the six-hour SEO renewal unchanged. The proven publication is already build-time HTML. Its source/media seal has a maximum 24-hour lifetime (or earlier media expiry), live address verification, withdrawals and current source identity. A deploy-only process can expire while no source deploy occurs, and catalog edits are not all deploy events. No durable catalog-change publication trigger/outage equivalent was established here. Removing cron, extending expiry or bypassing seals would reduce guarantees. Migration is therefore intentionally deferred; there is no partial migration to roll back.
- No HEIC conversion dependency was introduced. There is no established bounded, cross-browser decoder/converter in this project. Export/save JPEG instructions appear immediately; renaming a HEIC file is explicitly insufficient. Arbitrary formats/SVG/HTML remain rejected. Server decoding and private-copy verification remain authoritative, including for uncommon corruption a browser may tolerate. Provider/storage/quotas can still fail honestly after a locally valid file; Ready to upload is never an upload receipt.
- Checkout production flags were not read/changed. Existing enabled launch authorization, COD/InstaPay eligibility, pricing, stocks, discount allocation, snapshots, reference accounting, retention, CSRF/Origin/session boundaries and reconciliation/refund state machines remain. A screenshot never records receipt of funds. No automatic ambiguous resend/cancel/restart was added.
- Gift Box physical approvals, licenses, asset/source IDs and historic versions are retained. Their detailed management is deliberately secondary, not deleted. Collapsing a packing disclosure does not discard its editor state.
- CID logo bytes are the exact existing public PNG, duplicated into the backend deployment at a fixed path. No image was invented, redrawn or stretched. Offline MIME test confirms a single inline PNG with correct Content-ID and total message below 400 KB. A received Gmail test is still required after release.
